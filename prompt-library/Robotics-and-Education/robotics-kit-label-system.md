# Robotics Kit Label System

- **Category:** Robotics & Education
- **Provenance:** Reconstructed / polished from a robotics box-label prompt in the pinned-chat material titled “POLISH”; the original exact prompt and full specifications were not available.
- **Use case:** Design a consistent, readable label set for robotics kits, components, storage boxes, or student equipment.
- **Tags:** `#robotics` `#classroom` `#labels` `#print-ready` `#inventory`

## Copy-ready prompt

Act as a classroom resource designer and print-production specialist. Create a coordinated set of labels for my robotics classroom and equipment.

Use the exact names and inventory information I provide. Do not alter spelling, omit items, or invent equipment. Organize labels into clear categories such as kit names, component names, student/team names, and storage instructions where relevant.

Design requirements:
- Use a consistent visual identity that is friendly, modern, easy for children to recognize, and suitable for a robotics learning environment.
- Make every label readable at its actual printed size, with strong contrast and clear hierarchy.
- Use simple icons or visual cues only when they accurately represent the item.
- Keep label dimensions, spacing, alignment, and typography consistent.
- Avoid clutter and decorative elements that reduce legibility.
- Prepare an A4 print layout with sensible margins, cut lines or spacing, and no clipped text.
- Provide a proof list of every label so I can verify spelling and completeness before printing.

Before finalizing, compare the output against my supplied inventory and student-name list. Report any duplicates, missing entries, or ambiguous names rather than silently correcting them.

## Customization

Supply the complete equipment list, student/team names, label dimensions, paper size, preferred colours, and whether labels need to be waterproof or laminated.
