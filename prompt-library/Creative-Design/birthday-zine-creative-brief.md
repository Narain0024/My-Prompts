# Birthday Zine Creative Brief

- **Category:** Creative Design
- **Provenance:** Reconstructed / polished from a prompt-polishing request in the pinned-chat material titled “POLISH”; exact source wording was not available.
- **Use case:** Turn personal memories and supplied content into a cohesive, printable birthday zine.
- **Tags:** `#birthday` `#zine` `#editorial-design` `#print-design` `#creative-brief`

## Copy-ready prompt

Act as an experienced editorial designer and creative director. Create a distinctive birthday zine for `{{RECIPIENT}}` using the photos, messages, memories, inside jokes, and other content I provide.

First, review the supplied material and propose a clear concept, visual direction, page sequence, and tone. Then develop the zine page by page.

Requirements:
- Make it feel personal, warm, playful, and thoughtfully art-directed rather than like a generic birthday template.
- Use the supplied memories and wording accurately. Do not invent personal events or relationships.
- Establish a consistent palette, typography system, graphic language, and layout rhythm.
- Balance photographs, short captions, notes, mini-stories, lists, and decorative elements.
- Keep text readable and layouts practical for the requested print size.
- Provide page dimensions, bleed/margins, image placement guidance, and export recommendations for print.
- Flag missing assets and any text that needs confirmation.

Deliver the creative concept, page-by-page plan, exact draft copy, and production specifications. If image-generation prompts are useful, provide a separate prompt for each required illustration or visual asset.

## Customization

Provide recipient details, relationship, preferred tone, page count, print size, photos, and any must-include memories. Keep private or sensitive details out unless they are intentionally supplied for inclusion.
