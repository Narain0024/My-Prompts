# Contributing & Maintenance

This is a personal prompt library. Contributions should improve clarity and usefulness without changing the original task.

## Adding a prompt

1. Confirm that the prompt has a clear, reusable purpose.
2. Search `INDEX.md` for duplicates or near-duplicates.
3. Create a lowercase kebab-case `.md` file in the best-fit category.
4. Include all required metadata and the complete copy-ready prompt.
5. Mark provenance accurately: user-authored, user-developed/collaborative, or reconstructed/polished.
6. Add the prompt to `INDEX.md`.
7. Add uncertain or incomplete source material to `REVIEW-QUEUE.md` rather than filling gaps by guessing.

## Updating a prompt

- Preserve the original intent and non-negotiable constraints.
- For substantial changes, retain an `Original / source notes` section and add a new polished version.
- Add a dated entry to the file's change log.
- Do not silently replace a source prompt with a materially different task.

## Before publishing

- Remove secrets, personal identifiers, access tokens, private employee data, and confidential business information.
- Replace real names, phone numbers, email addresses, and internal paths with placeholders.
- Verify that all links and code examples are safe to publish.
- Check Markdown rendering and internal links.
- Confirm that assistant-generated content is labelled honestly.

## Suggested commit messages

- `docs: add payroll reconciliation prompt`
- `docs: refine smartphone comparison template`
- `docs: clarify prompt provenance`
