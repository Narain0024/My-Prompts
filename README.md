## ✨ About

Welcome to my personal **AI Prompt Library** — a continuously evolving collection of prompts gathered, refined, organized, and documented from practical use cases and experiments with AI tools.

Instead of keeping useful prompts scattered across conversations, notes, and documents, this repository brings them together in one structured and accessible place.

The goal is simple:

- Preserve useful prompts.
- Improve clarity and instruction quality.
- Make prompts reusable and adaptable.
- Organize prompts by practical application.
- Document prompt improvements over time.

This is not just a collection of AI commands. It is a growing knowledge base of prompt patterns, workflows, and experiments.

## 🧩 What Makes a Good Prompt?

Each curated prompt should aim to include:

1. **Role** — Define the expertise or perspective AI should adopt.
2. **Context** — Explain the situation and relevant background.
3. **Objective** — Clearly describe the expected outcome.
4. **Constraints** — Specify limitations, requirements, and preferences.
5. **Output Format** — Define how the response should be presented.
6. **Quality Criteria** — Establish what makes the result useful and successful.

Not every prompt needs all six elements, but each should have a clear purpose.

## 🚀 How to Use This Library

1. Browse `INDEX.md` to find a prompt.
2. Open the relevant Markdown file.
3. Copy the prompt.
4. Replace placeholders with your own information.
5. Run it in your preferred AI tool.
6. Refine the prompt based on the output.

**Tip:** Don't just copy prompts blindly. Adapt the context, constraints, and output requirements to your actual task.

## 🔄 Continuous Improvement

This repository is intended to grow through continuous refinement.

Prompts may be:
- Added when a useful new workflow is discovered.
- Refined when instructions can be improved.
- Merged when duplicate prompts are identified.
- Archived when they become outdated.
- Tested against different AI models where appropriate.

The review process also considers clarity, consistency, privacy, and practical usefulness.

## 🤝 Contributions

Suggestions and improvements are welcome.

If you have a better way to structure a prompt or discover a useful application:

1. Create or update the relevant Markdown file.
2. Follow `CONTRIBUTING.md`.
3. Maintain the quality guidelines in `PROMPT-QUALITY-STANDARD.md`.
4. Update `INDEX.md` when adding a prompt.

## ⚠️ Important Notes

- Some prompts are reconstructed or refined from earlier working notes and conversations.
- Not every prompt has been tested across multiple AI models.
- Results may vary depending on the AI model, context, and input.
- Never insert passwords, API keys, personal credentials, or confidential information into prompts.
